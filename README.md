# Shopora — Responsive E-commerce Website
A 15-page front-end e-commerce website made for a Web Engineering assignment using HTML5 and CSS3, with a small optional JavaScript file for the mobile navigation and demo form feedback.

## Pages (15)
1. Home — `index.html`
2. Shop — `shop.html`
3. Categories — `categories.html`
4. Product Details — `product.html`
5. New Arrivals — `new-arrivals.html`
6. Best Sellers — `best-sellers.html`
7. Deals & Offers — `deals.html`
8. About Us — `about.html`
9. Contact Us — `contact.html`
10. FAQs — `faq.html`
11. Shipping & Returns — `shipping.html`
12. Shopping Cart — `cart.html`
13. Checkout — `checkout.html`
14. My Account — `account.html`
15. Wishlist — `wishlist.html`

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser. No build tools or server are required.
3. Use the navigation menu and links to move between pages.
4. Resize the browser or open on a phone to test responsive styles.

## Project structure
- `index.html` and 14 other HTML pages: page content and navigation.
- `assets/style.css`: shared colors, layout, cards, forms, tables, responsive breakpoints.
- `assets/script.js`: small progressive enhancement for the mobile menu, quantity buttons, and demo form confirmation.

## Important limitations
This is a front-end coursework prototype. It does not have a database, real authentication, inventory, saved cart state, payment gateway, or real order submission. Forms display a demo confirmation only. Do not enter real payment or private information.

## Suggested viva explanation
- HTML gives the website structure: header, nav, main, sections, product cards, forms, tables, and footer.
- CSS gives the design: shared color variables, typography, spacing, cards, buttons, and responsive media queries.
- Responsive design uses CSS Grid/Flexbox and media queries to change columns and navigation on smaller screens.
- Reusable header/footer patterns keep pages consistent.
- Links between `.html` files implement multi-page navigation.
